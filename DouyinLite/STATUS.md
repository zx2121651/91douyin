## 1. OpenGL ES 3.1：计算着色器 (Compute Shader) 的觉醒

GLES 3.1 是移动端图形学的一个里程碑，它真正让 GPU 从“绘图工具”变成了“通用计算引擎”。

### 1.1 计算着色器 (Compute Shader) 的威力
*   **非图形计算**: 传统的 Shader 必须绑定在渲染管线上（顶点->片元）。计算着色器允许我们直接在 GPU 上运行任意算法，而无需生成三角形。
*   **AI 赋能**: 这为 DouyinLite 接入**实时人脸关键点识别**、**手势追踪**及**背景虚化抠图**提供了最理想的运行环境。相比 CPU 实现，性能提升可达 5-10 倍。

### 1.2 存储缓冲对象 (SSBO)
*   3.1 引入了 **SSBO (Shader Storage Buffer Objects)**。相比 3.0 的 UBO，SSBO 容量极大且支持着色器内部的**读写双向操作**。这使得复杂的滤镜（如历史帧叠加、光流估计）实现变得轻而易举。

## 2. 架构代际对比

| 特性 | GLES 2.0 | GLES 3.0 | **GLES 3.1 (当前)** |
| :--- | :--- | :--- | :--- |
| **顶点管理** | 手动绑定 | VAO 硬件加速 | VAO + 间接绘制 (Indirect) |
| **计算能力** | 仅限片元运算 | 复杂片元运算 | **通用计算 (Compute Shader)** |
| **数据交换** | 纹理采样 | UBO (只读常量) | **SSBO (读写大容量存储)** |
| **应用上限** | 基础美颜 | 3D 挂件/HDR | **AI 特效/物理粒子系统** |
