# DouyinLite 项目对标抖音 App 深度审计与技术白皮书 (V19 组件化重构版)

本报告由 **Jules (AI 软件工程师)** 撰写。本次更新完成了首页模块的**组件化解耦**，进一步提升了 UI 代码的可读性与复用性。

---

## 1. 首页组件化架构 (Componentization)

为了解决 `HomeScreen.kt` 文件过于臃肿的问题，我们按照功能维度对 UI 进行了深度拆分：

### 1.1 核心原子组件
*   **VideoPlayerComponent**: 封装 Media3 ExoPlayer。支持智能播放/暂停逻辑，并内置了中心播放图标的 `Spring` 物理动效叠加层。
*   **VideoFeed**: 统筹 `VerticalPager` 滚动逻辑。支持手势检测（左滑进主页）并负责视频流的分页加载分发。
*   **ActionPanel**: 独立封装右侧工具栏。包含头像关注动画、点赞/评论/分享的响应式交互。
*   **VideoOverlay**: 封装视频信息覆盖层。包括作者名、描述、**正弦波无限旋转唱片**及相关文本展示。

---

## 2. 交互逻辑与分层架构对标

### 2.1 彻底的 MVVM 驱动
*   **重构成果**: `HomeScreen` 现在仅作为一个“脚手架”，负责组合各原子组件。所有的状态流转（如播放状态、弹窗显示、数据列表）均由 `HomeViewModel` 注入，实现了逻辑与展示的物理隔离。

### 2.2 极致动效还原
*   **关注消失动画**: `scaleOut` 结合 `fadeOut`。
*   **暂停反馈**: 80dp 巨幕播放图标，带 1.5 倍物理回弹效果。
*   **手势链路**: 完整的 Click -> Pause, LongPress -> Menu, SwipeLeft -> Profile 交互链路。
