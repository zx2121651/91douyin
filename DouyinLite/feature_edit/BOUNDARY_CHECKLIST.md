# 编辑器边界校验清单 (Boundary Validation Checklist)

为了保证编辑器裁剪、封面选择与导出链路的稳定性，需覆盖以下校验场景：

## 1. 裁剪区间校验 (Clipping Boundaries)
- [ ] **最短视频限制**：裁剪后的片段时长不得低于 100ms（防止导出引擎崩溃或产生无效文件）。
- [ ] **前边界越界**：拖动左侧手柄不能小于 0。
- [ ] **后边界越界**：拖动右侧手柄不能超过视频源文件时长。
- [ ] **区间反转防止**：左侧手柄位置必须始终小于右侧手柄位置（至少保持 100ms 间距）。
- [ ] **多片段衔接**：多个片段裁剪后，导出总时长应等于各片段 `(end - start) / speed` 之和。

## 2. 封面选择校验 (Cover Selection)
- [ ] **时间轴一致性**：封面时间点必须位于总时间轴区间内 [0, TotalDuration]。
- [ ] **更新实时性**：用户在时间轴滑动并点击“封面”后，`coverTimestampMs` 应立即更新。
- [ ] **导出携带**：导出完成后，封面时间戳应正确传递至发布页。

## 3. 导出前置校验 (Pre-export Validation)
- [ ] **空项目拦截**：无主轨道视频或视频片段总时长为 0 时，禁止提交导出。
- [ ] **资源存在性**：校验所有 Clip 的 `sourceUri` 对应的本地文件是否依然存在。

## 4. UI 交互校验 (UI Verification)
- [ ] **手柄响应**：在 `TimelineArea` 中，只有选中的片段才会显示红色手柄。
- [ ] **预览同步**：调整手柄时，预览面板应实时跳至对应边界帧（Seek 预览）。
- [ ] **状态反馈**：设置封面后应有 Toast 或 Hint 提示用户设置成功。
